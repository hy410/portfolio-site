## 배포 (GitHub Pages)
1. 이 폴더의 파일을 저장소 루트에 업로드
2. Settings → Pages → Source: `Deploy from a branch`, Branch: `main` / `(root)`
3. `https://<username>.github.io/<repo>/` 에서 확인

## 상세 페이지 이미지 다시 넣기
1. 상세 페이지에서 `Shift + E` (또는 주소 끝에 `?edit`) → 숨겨진 빈 이미지 영역 표시
2. 빈 영역에 이미지를 드래그 앤 드롭
3. `Shift + E` 또는 우측 하단 "빈 이미지 영역 숨기기" 버튼으로 다시 숨김

※ 이미지 추가는 편집 환경에서 진행 후 `index.html`을 다시 받아 업로드하세요. (GitHub Pages에서는 드롭한 이미지가 저장되지 않음)
